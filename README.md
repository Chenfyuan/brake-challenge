# 极限刹车 · 点刹挑战

致敬网页游戏「极限刹车挑战」的原创复刻版：玩法与物理参数对齐，代码、Three.js 程序化美术、WebAudio 合成音效均为自研，不包含原作任何代码或素材。

## 玩法
- 全油门起步，车速 ≥100 km/h 后按住屏幕 / 刹车键 / 空格刹车，一旦刹车即切断动力
- 按住越久力度涨得越快，超过 **1612 N** 踏板断裂翻车；松开力度以 900 N/s 回落
- 在 2600 m 的路障前刹停才计分：`得分 = round(初速² / 刹车用时^1.7)`
- 车牌作昵称，成绩保存在本机排行榜（localStorage）

## 物理（定步长 1/120 s）
- 加速 `a = 7.4 × (1 − (v/Vmax)^1.55)`，Vmax = 260 km/h
- 按住：`F += (200 + 800·按住时长)·dt`
- 减速度 `= 10.8/1612·F + 0.15 + 2.2e-5·v²`
- 车头长 2.7 m，有效距离 2597.3 m；车速 ≤0.08 m/s 视为刹停
